## SciVer

The public router tables are derived from the SciVer benchmark:

- Paper: [SciVer: Evaluating Foundation Models for Multimodal Scientific Claim Verification](https://arxiv.org/abs/2506.15569)
- Dataset: [chengyewang/SciVer](https://huggingface.co/datasets/chengyewang/SciVer)
- Upstream dataset license: [Creative Commons Attribution 4.0 (CC BY 4.0)](https://creativecommons.org/licenses/by/4.0/)

This release excludes raw SciVer claims, captions, images, paper JSON files,
and gold labels. Users remain responsible for satisfying the upstream SciVer
license and citation requirements when using SciVer-derived artifacts.

## Cognitive-Difficulty Dimensions

The 12 cognitive-difficulty dimensions were engineered by the
[AI Faithfulness in Scientific Reasoning](https://github.com/Erdos-Projects/summer26-ai-faithfulness-in-scientific-reasoning)
project. This release acknowledges that contribution and does not claim to
relicense upstream project code or documentation. The public modeling table
contains only numeric derived feature values needed to reproduce the router
experiments.

## Generated Router Artifacts

Predictions, metrics, plots, and serialized router models were generated by
the scripts in this repository from the sanitized derived feature tables.
Serialized `.joblib` and `.pt` files should never be loaded from an untrusted
source; rerunning the public scripts is the recommended verification path.
